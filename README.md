🎮 Game Deals Scraper & Dashboard

A Python-based Game Deals Scraper and Dashboard that collects real-time game deal information and displays it in a simple and interactive web interface.

🚀 Features

* 🎮 Fetches real game deal data
* 🖼️ Displays game images
* 💰 Shows current and original prices
* 🔥 Displays discount percentages
* 🏆 Highlights the Best Deal
* 🏪 Shows store information
* 🔗 View Deal button
* 📊 Dashboard summary cards
* 🔎 Genre filter
* 💵 Maximum-price filter
* 🔄 Refresh functionality
* 📱 Responsive dashboard design

🛠️ Technologies Used

* Python
* Flask
* Requests
* BeautifulSoup
* HTML
* CSS
* CheapShark API

📊 Dashboard

The dashboard displays:

* Total Games
* Average Price
* Highest Discount
* Best Deal

🔎 Filters

Users can filter available games by:

* Genre
* Maximum Price

▶️ How to Run

1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder

```bash
cd GameDealsScraper
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the Flask application

```bash
python app.py
```

5. Open the application

Open:

```text
http://127.0.0.1:5000
```
